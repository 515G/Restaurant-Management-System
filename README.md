# نظام إدارة مطعم متكامل (Restaurant Management System)

مشروع جامعي متكامل لإدارة المطاعم وتسهيل عملية الطلبات وحساب الفواتير تلقائياً ومراقبة الطاولات، تم تطويره باستخدام لغة **#C** وواجهات **Windows Forms**.

## 🚀 الميزات الأساسية (Core Features)
* **عرض قائمة الطعام (Menu Display):** عرض ديناميكي لكافة الأصناف المتوفرة مع أسعارها.
* **إدارة الطلبات (Order Management):** إمكانية إضافة، تعديل، أو حذف الأصناف من سلة الطلب الحالية بسهولة.
* **حساب الفاتورة آلياً (Auto Billing):** يضمن حساب إجمالي الفاتورة تلقائياً بدقة عالية لمنع الأخطاء البشرية (باستخدام تقنيات LINQ).
* **إدارة الطاولات (Table Management):** تتبع حالة الطاولات ومحاكاة حجزها وتغيير حالتها عند إنهاء الطلب.
* **طباعة الفواتير:** استخراج فاتورة مفصلة تحتوي على رقم الطلب، التاريخ، الطاولة، والمجموع النهائي عند إتمام الدفع.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **اللغة الأساسية:** C# (.NET Framework)
* **الواجهة الرسومية:** Windows Forms (GUI)
* **أسلوب البرمجة:** البرمجة كائنية التوجه (OOP) لبناء هيكلية مرنة للمشروع.
